# جهاز التحري

يحوّل معرّفاً أو وثيقة إلى رسم بياني موثَّق للارتباطات بمصدر ودرجة ثقة.

## المسؤوليات

- استخراج المعرّفات من النصوص والملفات وتطبيعها
- تشغيل المحوّلات المسموحة عبر محرك القضية وتسجيل كل طلب خارجي
- ربط النتائج بنموذج الثقة وتفسير كل درجة (P4-001)
- ربط مؤشرات التهديد بـMITRE ATT&CK وCAPEC وD3FEND (P4-020)

## الحدود الحاكمة

- يخضع الجهاز لمبادئ الأخلاقيات E-01..E-10 (ROADMAP 3.5) وهي مفروضة في الكود.
- **E-04: لا أدوات هجومية.** لا يملك الجهاز أي قدرة هجومية أو وصول غير مصرّح به أو تعقب لأشخاص طبيعيين، ويُمنع ذلك بالاختبار (`organs.test.ts`).
- النضج الحالي: **ميثاق (charter)** — لا منطق تشغيلي بعد؛ يرتفع النضج بمهام لها كود واختبارات فقط.
