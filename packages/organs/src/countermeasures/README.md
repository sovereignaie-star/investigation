# جهاز المكافحة

استجابة مشروعة ودفاعية مبنية على نتائج التحري الموثَّقة.

## المسؤوليات

- حزم إحالة موثَّقة بالأدلة للجهات المختصة
- بلاغات إساءة لمزوّدي الاستضافة والنطاقات بمراجعة بشرية قبل أي إرسال
- تصدير مؤشرات التهديد MISP وOpenIOC وقوائم IOC للدفاع (P4-022)
- توثيق كل إجراء في سجل التدقيق غير القابل للتعديل

## الحدود الحاكمة

- يخضع الجهاز لمبادئ الأخلاقيات E-01..E-10 (ROADMAP 3.5) وهي مفروضة في الكود.
- **E-04: لا أدوات هجومية.** لا يملك الجهاز أي قدرة هجومية أو وصول غير مصرّح به أو تعقب لأشخاص طبيعيين، ويُمنع ذلك بالاختبار (`organs.test.ts`).
- النضج الحالي: **ميثاق (charter)** — لا منطق تشغيلي بعد؛ يرتفع النضج بمهام لها كود واختبارات فقط.

## الربط بالمشروع

الحزم: `@ir/core`، `@ir/ledger`، `@ir/egress`، `@ir/schema`.

المرجع: [ADR-32](../../../../docs/adr/ADR-32-three-organs.md).
