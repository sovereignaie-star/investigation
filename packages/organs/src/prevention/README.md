# جهاز الوقاية الجنائية

يحمي الأدلة والقضايا والمحقق قبل وقوع الضرر.

## المسؤوليات

- التحقق من سلامة سجل الأدلة وكشف أي تعديل صامت عليه
- فرض سياسة الخروج إلى الشبكة وعزل المحوّلات
- حماية بيانات القضايا بالتشفير المحلي وسياسة الاحتفاظ والحذف الآمن
- فحص الملفات المرفوعة بقواعد YARA وSigma محلية (P4-021)

## الحدود الحاكمة

- يخضع الجهاز لمبادئ الأخلاقيات E-01..E-10 (ROADMAP 3.5) وهي مفروضة في الكود.
- **E-04: لا أدوات هجومية.** لا يملك الجهاز أي قدرة هجومية أو وصول غير مصرّح به أو تعقب لأشخاص طبيعيين، ويُمنع ذلك بالاختبار (`organs.test.ts`).
- النضج الحالي: **ميثاق (charter)** — لا منطق تشغيلي بعد؛ يرتفع النضج بمهام لها كود واختبارات فقط.
