# خط اعتماد الأدوات من الكتالوج إلى محوّل (P2-021)

> يوثّق هذا الملف المسار الكامل الذي تمر به أي أداة من كتالوج الأدوات (`docs/tools/catalog.csv`) حتى تصبح محوّلاً معتمداً (`TR-xxx`) في `packages/transforms`. هو تنفيذ القسم 7.2 من الخارطة («خط اعتماد أداة من الكتالوج (Candidate → Certified)») ويُقرأ مع `docs/ROADMAP.md` §7.2–7.4 و`docs/adr/ADR-08-egress-gateway.md` و`docs/security/T-SBX_ENFORCEMENT.md`.

## لماذا هذا الخط؟

- **لا اختلاق:** كل محوّل يعتمد على مصدر حقيقي موثق في الكتالوج بمعرّف ثابت `TL-xxxxxxxx` (أول 8 خانات من SHA-1 للرابط المطبَّع).
- **ترشيح لا اعتماد:** وجود الأداة في الكتالوج لا يعني أن المشروع يستعملها. الاستعمال في الكود يمر بهذا الخط ويحصل على معرّف `TR-xxx`.
- **الأمن قبل السرعة:** أي مصدر جديد يدخل الكود يمر بخط 7.2 (GR-10)، ويُحدَّث القسم 7 في نفس الإيداع (GR-01). لا يُدمج محوّل بلا مراجعة أمنية (المرحلة 5) وبلا محاكاة حتمية.
- **D-048:** نقاط نهاية أطراف ثالثة بلا توثيق لحدودها وشروطها عيب معروف؛ هذا الخط يغلقها بإلزام توثيق الحدود والشروط في مرحلة التقييم (المرحلة 2).

## قواعد إلزامية عبر كل المراحل

1. **لا مفتاح في الكود أو السجلات أو الأدلة.** المفاتيح تُحقن من الخزنة عبر `secretProvider` في مسار الخروج (P2-016، D-031)، ولا تظهر في URL أو السجلات أو الأدلة غير المنقحة.
2. **الشبكة عبر `ctx.http` فقط.** المحوّل لا يملك `fetch` ولا `net` ولا `dns`؛ كل طلب يمر عبر `HttpTransport`/بوابة الخروج (ADR-08). أي محاولة اتصال مباشر تُفشل الاختبارات السلبية.
3. **محاكاة حتمية بلا شبكة حقيقية.** اختبارات القبول تعمل على `@ir/sim` (`createSimServer`) بلا اعتماد على خدمات عامة.
4. **حدود صريحة.** كل محوّل يعلن `limits: {rps, timeoutMs, maxBytes}` في بيانه، ويُنفَّذ في طبقة التنفيذ (بدلّة رمزية لكل تشغيل) وفي البوابة (لكل مضيف).
5. **فشل-مغلق.** غياب العزل أو فشل تهيئته يرفض التشغيل (`requireIsolation: true` → رفض) بلا fallback صامت (G-15).
6. **بوابة الأشخاص الطبيعيين.** أي مصدر حساسية «بوابة الأشخاص» (E-02) يمر ببوابة الأشخاص الطبيعيين (P2-013) قبل التوسع.
7. **كل نتيجة مربوطة بدليلها (P2-036).** كل استجابة من `ctx.http` تحمل `requestId` يعيّنه المشغّل عند إصدار الطلب، وكل نتيجة في تشغيل أجرى طلبات تذكر `evidence: [requestId, ...]` للاستجابات التي اشتُقت منها، أو `derivedFrom: "input"` إن حُسبت من المدخل وحده. المشغّل (داخل العملية والمعزول) يرفض: نتيجة بلا ربط، أو مرجعاً إلى طلب غير مسجل أو بلا استجابة، أو الجمع بين الاثنين، أو مخرجات ناجحة بعد طلب فاشل ابتلعه المحوّل (فشل لا نجاح فارغ). لا يُستنتج الربط من «آخر استجابة».
8. **توثيق الشروط.** فئة الترخيص (LC-A..LC-E) والقيود الكمية والجغرافية وشروط الاستعمال موثقة في ملف التقييم وفي بيان المحوّل (`license`).

## قالب المحوّل — `packages/transforms/src/transforms/tr-xxx-*.ts`

كل محوّل جديد يتبع بنية `tr-010-http-scan.ts` (المرجع):

```typescript
/**
 * TR-XXX — <الاسم> (P2-0XX).
 *
 * <وصف ما يفعله المحوّل، المصدر، فئة الترخيص، الحساسية، أي مفتاح.>
 */
import { defineTransform } from "../manifest.ts";
import type { TransformContext } from "../transform.ts";

export interface <Name>Input {
  /** <المدخل المعلن> */
  <input>: string;
}

export const <name> = defineTransform<<Name>Input>(
  {
    id: "TR-XXX",
    version: "1.0.0",
    inputs: ["<input>"],
    outputs: ["<output1>", "<output2>"],
    network: { mode: "public" | "pinned", allow: [] },
    secrets: [], // أو ["<secret>"] مع secretProvider في مسار الخروج
    limits: { rps: <n>, timeoutMs: <n>, maxBytes: <n> },
    sensitivity: "normal" | "natural_persons",
    license: "LC-<A|B|C|D|E>",
  },
  async (input, ctx: TransformContext) => {
    // T-RULE-02: URLs تُبنى بـ URL فقط.
    const url = new URL(input.<input>);
    // T-RULE-01: الشبكة عبر ctx.http فقط.
    const res = await ctx.http.get(url.toString());
    // T-RULE-03: المخرجات تمر عبر TransformOutputSchema.
    // P2-036: كل نتيجة تذكر الاستجابة التي اشتُقت منها.
    return { findings: [ /* { predicate, objectType, objectValue, confidence, explanation, evidence: [res.requestId] } */ ] };
  },
);
```

## فئات الترخيص (من §7.3)

| الفئة | المعنى | أمثلة |
|---|---|---|
| LC-A | محلي بالكامل، بلا شبكة | EXIF، libphonenumber، التجزئات الإدراكية |
| LC-B | عام بلا مفتاح، شروط تسمح بالاستعمال | DNS-over-HTTPS، RDAP، crt.sh، Wayback CDX |
| LC-C | مفتاح مجاني يوفره المستخدم | Companies House، GitHub token |
| LC-D | تجاري، مفتاح مدفوع يوفره المستخدم | Shodan، HIBP، OpenCorporates (حسب الخطة) |
| LC-E | قيود استخدام (غير تجاري أو إسناد إلزامي) | بعض مجموعات البيانات المفتوحة |

## العلاقة بالمهام الأخرى

- **P2-004** (SDK المحوّلات): يوفر `defineTransform`/`runTransform`/`TransformContext` التي يبني عليها كل محوّل.
- **P2-009/010/011/026/030** (دفعات المحوّلات): كل محوّل في هذه الدفعات يمر بهذا الخط.
- **P2-015/016** (المفاتيح): اختبار المفتاح لكل مزوّد وحقنه في الترويسات لا الروابط.
- **P2-021** (هذا الملف): يوثق الخط نفسه.
- **P2-022** (`ir run`): يشغّل أي محوّل معتمد من سطر الأوامر في عالم المحاكاة.
- **P2-023** (استراتيجيات التوسع): يستعمل `typeValue` (الثقة) و`transformCost` (التكلفة) من نتائج المحوّلات.
