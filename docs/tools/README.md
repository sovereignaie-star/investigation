# كتالوج أدوات «غرفة التحقيق»

كتالوج الأدوات والمصادر والواجهات التي يمكن أن يستعملها المشروع في **البحث** (جمع المعلومات وتحليلها) وفي **الاتصال** (واجهات برمجية ومصادر بيانات يتصل بها المحرك). الأرقام الدقيقة في [`STATS.md`](STATS.md) (مولَّد آلياً).

| المقياس | القيمة [مُقاس] بتاريخ 2026-10-10 |
|---|---|
| أدوات فريدة بعد إزالة التكرار | 10,834 |
| تستجيب أو موجودة خلف قيود الفحص الآلي | 9,711 |
| الطبقة الأساسية (من قوائم OSINT المتخصصة) | 6,557 |
| موسومة ببوابة الأشخاص الطبيعيين | 1,865 |
| مستبعدة بسياسة المنتج (هجومية أو مراقبة أشخاص) | 199 |
| القوائم المصدر | 19 قائمة عامة منسقة + إضافات منسقة من المالك (`tools/catalog/sources.json`، `tools/catalog/curated.json`) |
| المجالات | 22 مجالاً (`domains/*.md`) |

## مبادئ الكتالوج

| المبدأ | المعنى |
|---|---|
| لا اختلاق | كل مدخل رابط حقيقي مأخوذ من قائمة عامة مسمّاة، ويُذكر مصدره في عمود `sources` |
| ترشيح لا اعتماد | وجود الأداة هنا لا يعني أن المشروع يستعملها أو يوصي بها. الاستعمال في الكود يمر بخط الاعتماد (الخارطة 7.2) ويحصل على معرّف `TR-xxx` |
| قابل لإعادة البناء | `python3 tools/catalog/build.py` يعيد الجلب والتحليل والتصنيف وفحص الروابط |
| معرّفات ثابتة | `TL-xxxxxxxx` = أول 8 خانات من SHA-1 للرابط المطبَّع، فلا يتغير بين عمليات البناء |
| حدود أخلاقية | تُستبعد آلياً أدوات الاستغلال والتصيد والإغراق والتجسس ومراقبة الأشخاص (E-04)، وتُوسم أدوات الأشخاص والبريد والهاتف والتواصل ببوابة الأشخاص الطبيعيين (E-02) |
| الإسناد | الأوصاف القصيرة منقولة من القوائم المصدر. راجع ترخيص كل قائمة في مستودعها قبل إعادة النشر خارج هذا المشروع |

## حقول `catalog.csv`

| الحقل | المعنى |
|---|---|
| `id` | المعرّف الثابت `TL-xxxxxxxx` |
| `name`, `url` | الاسم والرابط كما في القائمة المصدر |
| `domain` | المجال (انظر الجدول أدناه) |
| `tier` | `core` من قوائم OSINT المتخصصة، `supporting` من قوائم داعمة (واجهات، جغرافيا، تحليل شبكات، أمن) |
| `kind` | `web` خدمة ويب، `oss` مستودع مفتوح المصدر، `api` واجهة برمجية، `dataset` مجموعة بيانات |
| `sensitivity` | `natural_person_gate` أو `standard` |
| `link_status` | `reachable` (2xx/3xx)، `restricted` (401/403/429… موجود لكنه يمنع الفحص الآلي)، `unreachable`، `unchecked` |
| `http` | رمز الاستجابة أو نوع الخطأ وقت الفحص |
| `auth`, `https`, `cors` | من public-apis فقط: نوع المصادقة، HTTPS، CORS |
| `sources` | القوائم التي وردت فيها الأداة (مفصولة بـ `;`) |
| `source_category` | القسم داخل القائمة المصدر |
| `description` | وصف قصير (≤ 240 حرفاً) |

## حدود معروفة [مُلاحظ]

| الحد | الأثر | المعالجة |
|---|---|---|
| التصنيف بالكلمات المفتاحية | بعض الأدوات في مجال غير دقيق، و`general` يحوي 1,300+ أداة | مراجعة يدوية تدريجية؛ تصحيحات في ملف تجاوزات لاحقاً |
| حالة الروابط لحظية | موقع «غير مستجيب» قد يعود، و«مقيّد» قد يعمل في المتصفح | إعادة البناء الدورية (R-20) |
| القوائم المصدر تحوي روابط عامة غير أدوات | بعض المدونات والصفحات العامة | تُرفض في مرحلة الفرز (7.2) |

## إعادة البناء

```bash
pip install aiohttp            # للفحص المتوازي للروابط
python3 tools/catalog/build.py # نحو 4 دقائق لفحص ~11,000 رابط
python3 tools/catalog/build.py --add-curated # يدمج tools/catalog/curated.json دون إعادة الجلب، ويفحص الروابط الجديدة فقط
```

أي إعادة بناء تُودَع مع تحديث `docs/STATUS.md` و`docs/WORKLOG.md` (GR-01).
