# خطة تنفيذ TR-026 — ملف OFAC SDN

> هذه ليست تقييماً إضافياً؛ توثيق خطة التنفيذ استناداً إلى التقييم في `TL-05f49117.md`.

## القرار الهندسي
- **المصدر:** ملف `sdn.xml` الرسمي (https://www.treasury.gov/ofac/downloads/sdn.xml) — مصدر أولي لا وسيط.
- **الحساسية:** `natural_person_gate` (E-02) — لا يعمل إلا بتأكيد غرض؛ لا يُوسَّع تلقائياً (لا يصبح نتيجة مطابقة اسم عقدة توسيع جديدة).
- **المفتاح:** لا.
- **الحد الأقصى للبايتات:** 8MB (الملف الفعلي 6-7MB).
- **النوع الجديد للكتالوج:** لا جديد — رقم SDN `sdn_uid` يُضاف عند التنفيذ (نمط رقمي).

## المخرجات المطلوبة
- لكل اسم مطابق: رقم SDN، نوع القائمة (SDN)، ونوع الكيان (فرد/كيان) فقط. لا ملف تعريف كامل.
