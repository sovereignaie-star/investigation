# تقييم TL-2b7cde30 — OpenSky Network (TR-040)

- **الرابط:** https://opensky-network.org/ (REST API: https://openskynetwork.github.io/opensky-api/rest.html)
- **المصدر في الكتالوج:** مصادر الطيران (رمز ICAO24/نداء ← رحلات)
- **تاريخ التقييم:** 2026-10-15
- **المقيِّم:** الوكيل الهندسي (المراجعة الأمنية: مراجعة D-8 على PR)

## القيمة للمستخدمين (PR-1..PR-6)
- يجيب عن: «ما الرحلات المرتبطة بهذا الطائرة (ICAO24) أو هذا النداء؟» — تحقق حركي لطائرة مشتبهة.

## الشروط والترخيص
- **الترخيص:** LC-C — **حساب مجاني بالتسجيل**؛ المصادقة حصراً OAuth2 client-credentials (منذ 2026-03-18 لم تعد كلمة المرور مقبولة): إنشاء API client من صفحة الحساب ثم `client_id` + `client_secret` (توكن Bearer صلاحيته 30 دقيقة).
- **الحدود:** نظام أرصدة: مستخدم مسجَّل 4,000 رصيد/يوم (مجهول: 400/يوم، وبيانات حالية فقط بلا تاريخ)؛ التكلفة حسب المساحة/الأيام المطلوبة.
- **المطلوب من المالك:** تسجيل حساب (مجاني) وإنشاء API client — **إجراء متاح للمالك فوراً**.

## الحساسية (E-02)
- عادي: طائرات ورحلات ليست أشخاصاً طبيعيين.

## الاستقرار
- خدمة بحثية عامة مستقرة منذ سنوات؛ المصادقة انتقلت إلى OAuth2 (2026) — مخطط موثق.

## القرار
- **فئة الترخيص:** LC-C.
- **القرار:** معلق حتى تسجيل المالك (مجاني) وإنشاء بيانات الاعتماد — البند **blocked على إجراء المالك** لا على قدرة فنية. عند توفر `client_id/client_secret`: التنفيذ مباشر (نمط TR-001 مع إدارة توكن OAuth2 في المشغّل).
