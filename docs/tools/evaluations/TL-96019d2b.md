# تقييم TL-96019d2b — Censys (الأصول والشهادات المكشوفة)

- **الرابط:** https://search.censys.io/ (الواجهة) — الواجهة البرمجية: https://search.censys.io/api/ (توثيق: https://docs.censys.com/docs/ls-api)
- **المصدر في الكتالوج:** مصفوفة اختبار المفاتيح (docs/security/KEY_TESTS.md) — المزوّد مدقق المصادقة (**زوج اعتماد** API ID + Secret عبر HTTP Basic)
- **تاريخ التقييم:** 2026-10-17
- **المقيِّم:** الوكيل الهندسي (المراجعة الأمنية: مراجعة D-8 على PR)

## القيمة للمستخدمات والمستخدمين (PR-1..PR-6)
- يجيب عن: «ما الخدمات المرصودة على هذا العنوان؟ وما الشهادات التي تغطي هذا النطاق؟» — سطح الهجوم المرصود علناً لكيان قيد التحقيق (IP أو نطاق)، بما يقوي ربط الكيانات وتحديد البصمة التقنية (PB-02/PB-04) — الخدمات المرصودة والشهادات المنشورة معلومة عامة أصلها مسح إنترنت دوري.
- يكرر جزئياً: لا يحل محل TR-010 (فحص HTTP نشط لوجه الخدمة) — TR-049 سجل رصد تاريخي لا فحص حي؛ ولا يحل محل TR-004 (CT) — TR-049 يشهد بالشهادة المرصودة على عنوان/نطاق من منظور المسح لا من منظور سجل الوساطة. يعزز كليهما.

## الشروط والترخيص
- **الترخيص:** حساب مجاني/مجتمعي بمفتاح واجهة — فئة LC-D (خطة مجتمعية بحصة محدودة). الشروط موثقة [مُتحقَّق 2026-10-17] من [شروط الاستخدام الرسمية](https://censys.io/terms): البحث والتحليل الداخلي المشروع مسموح؛ إعادة توزيع البيانات الخام مقيّدة؛ الاستعمال التجاري خارج نطاق الخطة قد يتطلب اشتراكاً.
- **حدود المعدل:** الخطة المجتمعية محدودة الحصة (موثقة من المصدر بحسب الطبقة)؛ rps 1 في البيان حدّنا المعلن (أضيق من أي حصة موثقة).
- **الحاجة لمفتاح:** نعم — **زوج اعتماد (API ID + Secret)** عبر HTTP Basic حصراً (موثق من [مرجع الواجهة الرسمي](https://docs.censys.com/docs/ls-api): «Every API call requires authentication with HTTP basic auth using the API ID and secret»). يُخزن الزوج كمدخل **واحد** من نوع credential_pair في الخزنة (مدخل `censys` — توسعة P2-026، L-31)، والـCLI يبني قيمة `Authorization: Basic base64(id:secret)` وتحقنها البوابة في الترويسة — لا يسافر أي جزء في الرابط أبداً (D-031).
- **القيود الكمية:** البحث الافتراضي صفحة واحدة (TR-049 لا يرسل `per_page` ولا `cursor` — عمداً: جمع أدنى، لا تصفح). الحد الأقصى لطول `q` غير موثق عند المصدر؛ 253 حدّنا المعلن (RFC 1123 §2.1).

## الحساسية (E-02)
- بوابة الأشخاص: لا تنطبق — البيانات خدمات وشهادات على بنية تحتية عامة، لا بيانات أشخاص طبيعيين. حساسية البيان `normal`. جمع أدنى عمداً: من عرض المضيف لا تُقرأ إلا الخدمات (منفذ/بروتوكول/اسم)، ومن بحث الشهادات لا يُقرأ إلا البصمة والأسماء المغطاة — الموقع الجغرافي واللافتات التفصيلية وDN المُصدر لا تدخل أي نتيجة.

## الاستقرار
- خدمة راسخة (Censys) — [مُلاحظ] من الصفحة العامة؛ لا يُدّعى أكثر.

## القرار
- **فئة الترخيص:** LC-D
- **القرار:** اعتماد TR-049 (موضوع IP عبر قالب المسار المغلق `/v2/hosts/{ip}`؛ موضوع النطاق عبر `q` حصراً في قائمة السماح المغلقة — رفض `per_page`/`cursor` عمداً؛ الزوج في ترويسة `Authorization: Basic` حصراً عبر البوابة، ومنع الإسناد: استجابة عن عنوان آخر تُرفض فاشلة-مغلقة، وشهادة لا تغطي النطاق المطلوب لا يُدّعى عليها)
