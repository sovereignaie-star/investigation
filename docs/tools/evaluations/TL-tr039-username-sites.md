# تقييم TL-tr039 — مواقع التحقق من وجود اسم مستخدم (TR-039)

- **المصادر:** صفحات/واجهات عامة بنمط وجود موثوق بالقياس (انظر القياس المؤرخ أدناه).
- **المصدر في الكتالوج:** قوائم بأسلوب Sherlock (ROADMAP P2-012).
- **تاريخ التقييم:** 2026-10-15 (قياسات حيوية مؤرخة 2026-10-15T21:10Z)
- **المقيِّم:** الوكيل الهندسي (المراجعة الأمنية: مراجعة D-8 على PR)

## القيمة للمستخدمين (PR-1..PR-6)
- يجيب عن: «أين يوجد حساب عام بهذا الاسم المستخدم؟» — **وجود فقط**، بلا أي محتوى (سياسة تقليل البيانات).

## القياسات المؤرخة (2026-10-15T21:10Z، طلبات عامة مفردة)
| الموقع | الطريقة | موجود | غير موجود | الدلالة |
|---|---|---|---|---|
| GitHub | صفحة الملف `github.com/{u}` | 200 | 404 | نظيفة — مطبقة |
| GitLab | واجهة عامة `api/v4/users?username=` | 200 + مصفوفة غير فارغة | 200 + `[]` | نظيفة — مطبقة (صفحة الملف نفسها تعيد 302 فلا تصلح) |
| Reddit | صفحة الملف و`about.json` | 301 / 403 | 301 / 403 | **غير قابلة للفحص بلا OAuth — مُسقط من القائمة** (L-14) |

## الشروط والترخيص
- **الترخيص:** LC-B — عام بلا مفاتيح؛ فحص واحد لكل موقع (GitHub: GET للصفحة؛ GitLab: GET لواجهة المستخدمين العامة).
- **الحدود:** rps 1.
- **القاعدة الأمنية:** أي استجابة خارج الدلالة الموثقة أعلاه تفشل التشغيل فشلاً-مغلقاً (403 حماية بوت أو 429 لا يُقرآن «لا حساب» أبداً).

## الحساسية (E-02)
- **بوابة أشخاص طبيعيين + غرض** (الخارطة): الاسم قد يحدد شخصاً — تأكيد غرض قبل التشغيل (نفس صنف TR-014).

## الاستقرار
- GitHub وGitLab مستقران منذ سنوات بأنماط موثقة؛ تغيّر النمط أسوأ حالة = فشل ظاهر (لا نتيجة صامتة خاطئة). توسيع القائمة لاحقاً يتطلب قياساً مؤرخاً لكل موقع جديد.

## القرار
- **فئة الترخيص:** LC-B.
- **القرار:** تنفيذ فوري (GitHub + GitLab)؛ Reddit مؤجل حتى توفر OAuth (حد معلن L-14).
