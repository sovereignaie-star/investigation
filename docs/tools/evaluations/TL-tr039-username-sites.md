# تقييم TL-tr039 — مواقع الملفات العامة للتحقق من وجود اسم مستخدم (TR-039)

- **المصادر:** صفحات ملفات عامة بنمط URL ثابت وموثوق: GitHub (`github.com/{u}`)، Reddit (`www.reddit.com/user/{u}`)، GitLab (`gitlab.com/{u}`).
- **المصدر في الكتالوج:** قوائم بأسلوب Sherlock (ROADMAP P2-012).
- **تاريخ التقييم:** 2026-10-15
- **المقيِّم:** الوكيل الهندسي (المراجعة الأمنية: مراجعة D-8 على PR)

## القيمة للمستخدمين (PR-1..PR-6)
- يجيب عن: «أين يوجد حساب عام بهذا الاسم المستخدم؟» — **وجود فقط**، بلا أي محتوى (سياسة تقليل البيانات).

## الشروط والترخيص
- **الترخيص:** LC-B — صفحات عامة بلا مفاتيح؛ الفحص طلب GET واحد لكل موقع.
- **الحدود:** rps 1 (مهذب مع ثلاثة مواقع فقط — قائمة منسقة صغيرة بقرار موثق: استقرار نمط 200/404 موثق لكل موقع، وبلا حماية بوت تُفسد الدلالة).
- **دلالة الحالة:** 200 => وجود؛ 404 => لا وجود؛ **أي حالة أخرى تفشل التشغيل فشلاً-مغلقاً** — حماية البوت (403) أو تحديد المعدل (429) لا يُقرآن أبداً «لا حساب».

## الحساسية (E-02)
- **بوابة أشخاص طبيعيين + غرض** (الخارطة): الاسم المستخدم قد يحدد شخصاً — يتطلب تأكيد غرض قبل التشغيل (نفس صنف TR-014).

## الاستقرار
- المواقع الثلاثة مستقرة منذ سنوات بأنماط ملفات ثابتة؛ تغيّر النمط أسوأ حالة = فشل ظاهر (لا نتيجة صامتة خاطئة).

## القرار
- **فئة الترخيص:** LC-B.
- **القرار:** تنفيذ فوري — لا مفاتيح ولا تبعيات؛ القائمة منسقة (ثلاثة مواقع) وقابلة للتوسعة لاحقاً بقرار موثق لكل موقع جديد (نمط 200/404 مستقر شرطاً).
