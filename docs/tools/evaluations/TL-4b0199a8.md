# تقييم TL-4b0199a8 — Companies House (المملكة المتحدة)

- **الرابط:** https://find-and-update.company-information.service.gov.uk/ — سجل الشركات الرسمي في المملكة المتحدة
- **المصدر في الكتالوج:** Jieyab89/OSINT-Cheat-sheet; lockfale/OSINT-Framework — Compliance & Risk Intelligence / KYC / AML Tools (TL-4b0199a8)
- **تاريخ التقييم:** 2026-10-15
- **المقيِّم:** الوكيل الهندسي (المراجعة الأمنية: مراجعة D-8 على PR)

## القيمة للمستخدمين (PR-1..PR-6)
- يجيب عن: «ما هذه الشركة البريطانية؟ من مديروها؟ من أصحاب السيطرة الجوهرية (PSC)؟»
- مصدر أولي (سجل حكومي) لا وسيط.

## الشروط والترخيص
- **الترخيص:** وسيط مع مفتاح مجاني (LC-C) — الواجهة البرمجية الرسمية (developer.company-information.service.gov.uk) تحتاج تسجيلاً مجانياً ومفتاح CH API key.
- **حدود المعدل:** معقول في الطبقة المجانية؛ 1/ث تحوطاً.
- **الحاجة لمفتاح:** نعم (مجاني بالتسجيل).
- **القيود الكمية والجغرافية:** الشركات البريطانية فقط.
- **شروط الاستعمال:** شروط الخدمة تتطلب حساباً مجانياً.

## الحساسية (E-02)
- حقل المديرين وPSC (أشخاص طبيعيون) يتطلب `natural_person_gate`؛ حقل الشركة نفسه عادي.

## الاستقرار
- واجهة برمجية مستقرة وموثقة؛ لا مفتاح = لا تشغيل (فشل-مغلق قبل أي طلب).

## القرار
- **فئة الترخيص:** LC-C (مفتاح مجاني بالتسجيل)
- **القرار:** تعليق TR-023 حتى توفر مفتاح فعلي — التنفيذ بلا مفتاح سيفشل في كل تشغيل ويستهلك ميزانية الطلب. المستند يوثق التعليق وأسبابه.

## مراجعة مؤرخة 2026-10-15
- **حيوية المصدر:** `https://api.company-information.service.gov.uk/search/companies?q=test` => HTTP 401 (0.37 ث) — الخدمة حية والمصادقة مطلوبة كما هو موثق.
- **المطلوب لفك التعليق:** مفتاح مجاني بالتسجيل (LC-C) — **إجراء متاح للمالك فوراً** (التسجيل مجاني): بمجرد تسجيل المالك وحصوله على مفتاح API يمكن تنفيذ TR-023 دون أي عائق آخر.
- **ما يمكن إنجازه الآن:** لا شيء تنفيذي بلا مفتاح؛ تسجيل المالك هو خطوة المالك.
- **المتبقي blocked:** المفتاح (قرار/إجراء مالك).

## التنفيذ 2026-10-16 (بعد تفعيل المالك التسجيل المجاني)
- **توجيه المالك (2026-10-16، موثق في صف P2-011):** المالك فعّل التسجيل المجاني والمفتاح يُسلّم عبر الآلية الآمنة المعتمدة `IR_COMPANIES_HOUSE_TOKEN` لا في المحادثة.
- **التنفيذ (نمط TR-028):** `tr-023-companies-house.ts` — المفتاح يُقرأ من البيئة وقت التشغيل (`IR_COMPANIES_HOUSE_TOKEN`) ويسافر في ترويسة `Authorization` (Basic بالمفتاح اسم مستخدم) لا في الرابط أبداً؛ بلا مفتاح يفشل التشغيل-مغلق قبل أي استدعاء نقل (اختبار مقيس: صفر طلبات). البيان يعلن `env: ["IR_COMPANIES_HOUSE_TOKEN"]` فيسلّم المشغّل المعزول الاسم وحده عبر IPC (نمط إصلاح TR-028).
- **العمليتان:** رقم شركة ← الملف + المسؤولون + PSC (3 طلبات؛ النشط فقط — المستقيل والمتوقف يتخطيان)؛ اسم شركة ← بحث السجل (طلب واحد) يعيد أرقام التسجيل (تتغذى التوسعة على مسار الرقم).
- **الأدلة:** 9 اختبارات عقد في `tr-023.test.ts` (7 داخل العملية + 2 معزولتان على مسار الإنتاج) — منها: المفتاح في الترويسة لا الرابط (مقيس على كل طلب)، 404 سلبية لا خطأ، 401 يرفض التشغيل، مدخل غير صالح يُرفض قبل أي طلب، وقيمة لا تطابق نمط نوعها تُتخطى (D-018).
- **حد جديد مكتشف وأصلح (أحمر أولاً):** مسار العزل كان يسقط ترويسات الطلب في IPC (`op:"fetch"` كان يحمل method+url فقط) — فُحص أحمر عبر اختبار TR-023 المعزول ثم أصلح: الترويسات تُمرر الآن عبر IPC مع تحقق صارم من شكلها (سلسلة→سلسلة فقط)، والأدلة المسجلة لا تتضمن الترويسات أصلاً فلا يصل المفتاح إلى السلسلة.
- **حد معروف موثق:** الكتالوجان أضيفا نوعين (`uk_company_number` و`company_name` متعدد الكلمات مع context.required — درس TR-036) والاختبار الذهبي أخضر (10/10).
