# Abuse-Report Channel

**Date:** 2026-10-24 — **Task:** P6-015 — **Signature:** Engineering lead under owner mandate. Subject to independent legal review (P7-008).

## Reporting channel

To report abuse of the tool (unlawful stalking, impersonation, or violation of source terms):

- **Private channel (preferred):** a private security advisory in the repository — https://github.com/sovereignaie-star/investigation/security/advisories
- **Public channel:** an Issue in the repository — https://github.com/sovereignaie-star/investigation/issues

## What a report should include

1. A description of the alleged abusive use and its evidence if any (link/identifier)
2. Any technical artifact you observed (product/report/repository)
3. If the report concerns a vulnerability in the tool itself, the same channel works (responsible disclosure — disclosure policy P7-007)

Do not include more natural-person data in the report than needed to understand it.

## Response

- Security reports (vulnerabilities): triaged per the disclosure policy in [SECURITY.md](../../SECURITY.md) (P7-007) — no absolute time window promised before approval; the plan is shared in the reply.
- Abuse reports: the project's decision-makers review and decide — the tool is local, we hold no remote access to users' machines, so the systemic response (policies/documentation/release) is the remedy, not an action on other people's devices.
- Bad-faith reports or ones violating the terms of use are closed with a documented decision.
