# 8. التقرير والتصدير والتبادل (REPORTING)


## 8.1 قدرات التقرير

- تقارير عربية/إنجليزية ذات اتجاه RTL/LTR صحيح، وفهرس، وملخص تنفيذي، ومنهجية، ومصادر، وسجل الأدلة، وخط زمني، وعلاقات، وقيود، وتعارضات، وتوصيات مفصولة عن الوقائع.
- إخراج PDF/HTML/DOCX/CSV/JSON مع تحقق من أن النصوص غير الموثوقة لا تحقن HTML أو CSS أو JavaScript.
- قوالب متعددة حسب نوع التحقيق وتصنيفه وحساسيته، وحجب تلقائي للمعلومات الحساسة حسب الصلاحية.
- تتضمن كل صورة/جدول/استنتاج مرجعاً إلى الأدلة التي تدعمه.
- نسخة التقرير وبصمته وتوقيعه وسجل إعادة إنتاج البيانات التي بُني منها.

## 8.2 صيغ التبادل

- JSON وCSV وNDJSON للإخراج التشغيلي.
- STIX 2.1 وTAXII 2.1 لمعلومات التهديدات عندما تتطابق دلالات البيانات.
- MISP format/connectors وOpenCTI connectors.
- GraphML وGEXF لتبادل الرسوم البيانية.
- W3C PROV-O أو نموذج provenance واضح، وCASE/UCO حيث تكون ملاءمة قانونية/تقنية مثبتة.
- SARIF لمخرجات فئات تحليل الأكواد المناسبة، وSBOM CycloneDX/SPDX في أدوات سلسلة الإمداد.
- كل exporter يملك schema validation وround-trip tests حيث يكون ممكناً؛ لا تصدّر كياناً غير مدعوم إلى نوع معيار غير مطابق لمجرد تسهيل التحويل.

## 8.3 أدوات مرشحة
Puppeteer، Playwright، Typst، LaTeX، Pandoc، WeasyPrint، Apache POI/ExcelJS، Graphviz، Gephi، Cytoscape، MISP، OpenCTI، TheHive، أنظمة SIEM/ITSM المصرح بها.
