# P5-027 — مقارنة محركات PDF للتقارير العربية (Typst / Playwright / React-PDF)

التاريخ: 2026-10-24 — الأحمر أولاً: اختبارات T-REP-009..012 كُتبت قبل التنفيذ وفشلت (renderReportPdf كان يرفض صريحاً حتى قرار المحرك — سلوك T-REP-009 القديم)، ثم نُفّذ القرار.

## التقرير المرجعي

نفس تقرير اختبار `packages/reports/src/reports.test.ts` (validDoc): عنوان «تقرير فحص النطاق example.test»، قضية case-001، جملتان لكل منهما إحالة إلى دليل (EV-1/EV-2)، وملحق أدلة. يُطبع بالمحركات الثلاثة (حصن قابل لإعادة التشغيل: `tools/pdf-comparison/`).

## القياسات [مُقاس]

| المعيار | Typst 0.10 | Chromium (Playwright) | React-PDF 4.9 |
|---|---|---|---|
| تشكيل العربية (فحص مرئي لصور الصفحات) | سليم — حروف متصلة RTL صحيح | سليم — حروف متصلة RTL صحيح | **مكسور** — حركات/نقاط مشوهة («"» مكان التشكيل) وأشكال سياقية خاطئة |
| BiDi عند خلط عربي/لاتيني/أرقام | صحيح | صحيح | **مبعثر** — ترتيب معكوس للجملة |

| استخراج النص (pdfjs + NFKC) | أشكال عرض تُطبَّع إلى الحروف (سليم) | **منطقي مباشر** (pdftotext يعطي الجملة الصحيحة بترتيب القراءة) | محارف تحكم مهملة (\u0001، \u0005، \u000e) — طبقة ToUnicode تالفة |

| مصدر القالب | يحتاج قالباً ثانياً خاصاً به | **قالب HTML نفسه** (مصدر حقيقة واحد) | يحتاج قالباً ثانياً (React) |

### التفصيل

1. **React-PDF مرفوض** — العيب قاتل ولا يقبل التجميل: التشكيل العربي نفسه مشوه (راجع صورة الصفحة في القياس المرئي: «تقرير» تُرسم بحركات مكانها علامات اقتباس، والجملة تُقرأ بترتيب معكوس). كشفه الاستخراج (محارف تحكم) والفحص المرئي معاً.
2. **Typst صحيح لكنه يخسر الهندسة** — إضافة قالب Typst يعني تنفيذ عرض التقرير مرتين (HTML + Typst) مع خطر تباعد دائم بينهما؛ حزمة npm الرسمية مثبتة على 0.10 (المترجم الحالي أحدث بكثير) وتنزّل ثنائياً وقت التثبيت من GitHub Releases؛ ويحتاج هو أيضاً تثبيت الطوابع للحتمية.
3. **Chromium (Playwright) هو المختار** — قالب HTML نفسه يعني نفس التقرير في المعاينة والتصدير؛ أفضل استخراج نصي (عربي منطقي)؛ Playwright موجود أصلاً في المستودع (e2e)؛ الحتمية حُلّت بتثبيت متساوي الطول لطوابع التاريخ (`normalizePdfDates` — مرآة `pinDocxTimestamps` للـ DOCX) — يثبته T-REP-011 (بايت-ل-بايت).

## القرار

ADR-35 (`docs/adr/ADR-35-pdf-engine.md`): Chromium عبر Playwright على قالب HTML. React-PDF مرفوض بقياس؛ Typst وثائق بديل معلن.

## الجودة

- T-REP-009..012 (4 اختبارات جديدة) خضراء؛ ملف التقارير كاملاً 12/12.
- فشل-مغلق: لا Chromium (مضمّن أو نظامي عبر CHROME_PATH/PATH — سابقة G-11) = خطأ صريح بلا PDF صامت.

## حدود معلنة (DECLARED_LIMITS L-P5-027)

النشر يحتاج Chromium في بيئة التشغيل (متصفح Playwright المضمّن أو Chrome نظامي) — حاوية الخادم الحالية لا تشمله؛ فشل توليد PDF فيها صريح بلا صمت. رجوع النظامي (fallback) إلى Chrome النظامي مقيس على مستودع GitHub ubuntu-latest (سابقة G-11) لكنه غير مقيس على كل بيئة نشر.
