# دليل الأحمر — P6-002 (نمذجة التهديدات STRIDE)

**التاريخ:** 2026-10-24
**الفرع:** `feat/P6-002-stride`
**الحالة قبل التنفيذ (الأحمر):** لا يوجد `docs/security/threat-model.md` إطلاقاً — نمذجة P2-003 غطت البنية الشبكية (T-SEC-SSRF وسجل القبول) لكن لا نموذج STRIDE منهجي شامل لكل حدود الثقة.

## الاختبار الأحمر (T-TM-001..005)

```
$ node --test scripts/governance/threat-model.test.mjs
ℹ pass 0

```

الفشل الخمسة: النموذج غير موجود فتفشل كل الفحوص: التوقيع، الفئات الست، سلامة الأعمدة/الأدلة، تغطية حدود الثقة الست (ADR-08/P2-003)، وفرادة المعرفات.

## لماذا هذا اختبار لا مجرد وثيقة

- كل تهديد يجب أن يحمل **تخفيفاً بدليل قابل للتحقق** (ملف موجود أو مرجع T-/G-/ADR/PR) أو يُعلن **خطراً متبقياً صريحاً** — لا ادعاء تخفيف بلا مصدر.
- كل حد ثقة من ADR-08 (المتصفح↔الخادم، الخادم↔البوابة، البوابة↔المزودون، الخادم↔العزل، الخادم↔المخزن، المشغّل↔CLI) يجب أن يظهر — لا حد ثقة بلا تهديدات.
- المعرفات فريدة (TM-فئة-رقم) والفئات الست ≥5 تهديدات لكل فئة — لا فئة تُنسى.

## ملاحظة حوكمة (شرط القبول «مراجعة ثانية»)

مراجعة D-8 ملغاة نهائياً بأمر المالك التأسيسي (الجلسة الحالية) — لا مراجع بشري. شرط «مراجعة ثانية» في صف الخارطة يُستوفى بقرار المالك المذكور: الحارس الآلي هنا هو «المراجعة الثانية» (كل ادعاء تخفيف موثق بمصدر قابل لإعادة التشغيل)، والاعتماد الخارجي يبقى P6-003.
