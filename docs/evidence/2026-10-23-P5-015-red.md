# P5-015 — الأحمر أولاً (RED): استخراج الكيانات من الوثائق بالذكاء الاصطناعي (اقتراحات)

التاريخ: 2026-10-23 — الترتيب: اختبارات T-ENT-001..006 كُتبت قبل وجود الميزة، وشُغّلت ففشلت كلها (suggestEntities is not a function)، ثم نُفّذت.

## الأحمر الموثق (قبل التنفيذ)

```
$ pnpm vitest run packages/ai/src/extract.test.ts

TypeError: suggestEntities is not a function — 6 فشلاً
```

## التنفيذ

- **اقتراحات لا تأكيدات:** `suggestEntities` في `@ir/ai` — كل اقتراح «غير مؤكد» بالتصميم: النوع يحمل `uncertain: true` و`status: "suggestion"`، ولا يوجد في الواجهة أي مسار تأكيد آلي — التوثيق في القضية يحتاج موافقة بشرية (E-07).
- **تحقق حتمي من الناتج:** ناتج النموذج يُحلل JSON ثم يُتحقق بمخطط صارم — أنواع كيانات معروفة فقط (person, organization, domain, email, ip, wallet, phone, saudi_id, national_id, iban, url — لا أنواع مختلقة تعبر)، وقيم غير فارغة، وبنية اقتراحات — فشل صريح مصنف (لا صمت ولا اقتراحات فارغة تمر).
- **الحصر (P5-014):** الوثيقة تدخل داخل علامات «بيانات غير موثوقة» (مع تعقيم محارف العلامات)، وتعليمات النظام تنص أن ما بينها بيانات لا تعليمات — والتعليمات المدسوسة في الوثيقة تبقى داخل العلامات ولا تصعد إلى النظام (T-ENT-006).
- **عيب مكتشف:** دالة التعقيم كانت غير مصدّرة من وحدة الحقن — اكتُشف بفشل الاختبارات وأُصلح (تصدير).

## القياس

- T-ENT-001..006 (6 اختبارات): كلها خضراء — الاستخراج عبر المزوّد المحلي، عدم اليقين بالتصميم، رفض JSON غير المخول، رفض الأنواع المختلقة، التعليم الصريح بالحصر، والحقن محصور.
- الحزمة الكاملة **2921/0/6 (+6)**؛ lint/typecheck/build/governance exit 0.

## حدود معلنة

- الاستخراج يعتمد على التزام النموذج بالتعليمات — التحقق الحتمي يضرب الأنواع المختلقة والبنية الفاسدة، لكن قيمة مختلقة «بشكل صحيح» (اسم غير موجود في الوثيقة) تمر — الضابط البشري (اقتراح غير مؤكد يراجعه المحقق) هو خط الدفاع الأخير، وهذا مقصود التصميم.
- ربط الاقتراحات بواجهة القضية (مراجعة المحقق وقبوله) ليس نطاق هذه المهمة.
