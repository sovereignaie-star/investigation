# P5-018 — الأحمر أولاً (RED): اقتراح الخطوة التالية وتوليد فرضيات مع تبرير بالأدلة

التاريخ: 2026-10-23 — الترتيب: اختبارات T-NBA-001..006 كُتبت قبل وجود الميزة، وشُغّلت ففشلت كلها (suggestNextActions is not a function)، ثم نُفّذت.

## الأحمر الموثق (قبل التنفيذ)

```
$ pnpm vitest run packages/ai/src/next-action.test.ts

TypeError: suggestNextActions is not a function — 6 فشلاً
```

## التنفيذ — القواعد الأربع

1. **كل اقتراح يذكر الأدلة التي بُني عليها:** إحالات أدلة إلزامية — بلا إحالة أو بإحالة خارج النطاق يُرفض الاقتراح ويُعلن (rejected بمقدار رفضه)، وسند المضمون: تراكب كلمات المحتوى بين التبرير والأدلة المُحالة (تحقق حتمي مستقل عن النموذج).
2. **موسوم «غير مؤكد» ولا يُنفَّذ إلا بموافقة المستخدم (E-07):** لا مسار تنفيذ في الواجهة أصلاً — اقتراحات فقط؛ التنفيذ قرار المحقق.
3. **لا يقترح مساراً يتجاوز بوابة الأشخاص (P2-013):** اقتراح يستهدف كياناً شخصياً (person, phone, email, saudi_id, national_id, iban) يوسم `requiresPurposeConfirmation` — والبوابة نفسها في المحرك عند التشغيل اليدوي.
4. **الحصر (P5-014):** حالة القضية (أدلة/كيانات/تغطية) تدخل داخل علامات «بيانات غير موثوقة» مع تعقيم المحارف، والتعليمات المدسوسة لا تصعد إلى النظام.

## عيوب مكتشفة أثناء الدورة (موثقة بصدق)

1. **رفض كاذب في سند التبرير:** اقتراحات مخلصة رُفضت (سند مقيس 0.25-0.46 دون 0.4) — التشخيص: محلل الرموز لا عتبة السند: (أ) علامات التشكيل العربية (الشددة والتنوين) تفصل الكلمة وهمياً («يسجّل» ترمزان «يس»+«ل»)؛ (ب) النقطة الطرفية ترمز («2026.» ≠ «2026»). أُصلح المحلل (حذف \p{M} والتطويل، والرمز يبدأ وينتهي بحرف/رقم) — وحسّن قياس السند لكل مستخدمي المحلل (P5-013/015/018).
2. **عيوب إعداد اختبار وواجهة:** تبريرات الاختبار الأولى لم تكن مبنية على أدلة (رفضها التحقق — سلوك صحيح)؛ وشكل النتيجة في الاختبار (action.transformId) خالف التنفيذ — صُححا.
