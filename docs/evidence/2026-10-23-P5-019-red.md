# P5-019 — الأحمر أولاً (RED): السؤال بلغة طبيعية عن القضية، مقيد بالأدلة

التاريخ: 2026-10-23 — الترتيب: اختبارات T-QA-001..006 كُتبت قبل وجود الميزة، وشُغّلت ففشلت كلها (answerCaseQuestion is not a function)، ثم نُفّذت.

## الأحمر الموثق (قبل التنفيذ)

```
$ pnpm vitest run packages/ai/src/qa.test.ts

TypeError: answerCaseQuestion is not a function — 6 فشلاً
```

## التنفيذ

- **الإجابة تحيل كل جملة بدعوى إلى دليل (T-AI):** إحالة [n] إلزامية محلة (خارج النطاق → غير مدعومة) وسند مضمون بتراكب كلمات المحتوى (تحقق حتمي مستقل — كالـ P5-013).
- **«لا أعلم» حين لا يوجد دليل:** الامتناع الصريح جواب مقبول موسوم (abstained=true, ok=true) لا فشل — الصدق أفضل من الاختراع.
- **الدعاوى غير المدعومة تُكشف وتُعلن:** بلا إحالة، أو بإحالة مكسورة [9]، أو بغير سند — تُسرد (unsupported) ولا تُمرر صامتة.
- **الحصر (P5-014):** الأدلة تدخل داخل علامات «بيانات غير موثوقة» مع تعقيم المحارف، والتعليمات المدسوسة لا تصعد إلى النظام.
