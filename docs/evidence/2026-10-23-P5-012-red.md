# P5-012 — الأحمر أولاً (RED): `@ir/ai` واجهة مزوّد ومحلي افتراضياً

التاريخ: 2026-10-23 — الترتيب: اختبارات T-AI-001..007 كُتبت قبل وجود الحزمة، وشُغّلت ففشلت (Cannot find module './index.ts')، ثم بُنيت الحزمة.

## الأحمر الموثق (قبل البناء)

```
$ pnpm vitest run packages/ai

Error: Cannot find module './index.ts' imported from .../packages/ai/src/provider.test.ts
```

## التنفيذ (حزمة `@ir/ai` جديدة)

- **الافتراضي محلي (السيادة أولاً):** المزوّد المحلي يتكلم عقد Ollama حرفياً (POST /api/chat) — يُثبت «يعمل مع نموذج محلي» ضد خادم اختبار محلي يتكلم البروتوكول نفسه (لا بديل مختلق). بلا مفتاح وبلا شبكة خارجية.
- **السحابي بموافقة صريحة لكل قضية:** بلا موافقة موثقة يُرفض كل استدعاء صريحاً (فشل-مغلق)، وبها تُطبع الموافقة في كل استدعاء (تتبع). فشل المحلي خطأ مصنّف — لا احتياط سحابي صامت أبداً.
- **تنسيق صرف (ADR-08):** الحزمة بلا أي مسار شبكة مباشر — النقل يُحقن (`AiTransport`)؛ بلا نقل محقون تُرفض الاستدعاءات صريحاً. ملفات الاختبار وحدها تفتح منافذ محلية (مسموح وموثق في حارس no-direct-network — الحارس أخضر).
- **عيب حقيقي مكتشف أثناء الدورة:** استدعاء السحابي عبر ترويسة عربية غير مشفرة (غرض الموافقة) — ترويسات HTTP لا تحمل غير بايتات لاتينية؛ يُشفر الغرض (encodeURIComponent). وخطأ صريح بلا ابتلاع لأخطاء النقل وHTTP.
