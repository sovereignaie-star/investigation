# P5-010 — الأحمر أولاً (RED): `@ir/reports` قوالب HTML/PDF/DOCX بإحالات

التاريخ: 2026-10-23 — الترتيب: اختبارات T-REP-001..009 كُتبت قبل وجود الحزمة، وشُغّلت ففشلت (Cannot find module './index.ts')، ثم بُنيت الحزمة.

## الأحمر الموثق (قبل البناء)

```
$ pnpm vitest run packages/reports

Error: Cannot find module './index.ts' imported from .../packages/reports/src/reports.test.ts
```

## التنفيذ (حزمة `@ir/reports` جديدة)

- **النموذج (UC-14):** تقرير = أقسام تحتوي عبارات، كل عبارة تحمل إحالات إلى أدلة في الملحق. فاشل-مغلق مزدوج: عبارة بلا إحالة تُرفض عند البناء، وإحالة إلى دليل غير موجود في الملحق تُرفض (لا إحالات معلقة).
- **HTML:** قالب حتمي كامل — RTL للعربية، علامات إحالة قابلة للنقر [n] تحيل إلى ملحق الأدلة (مع البصمات)، بلا طوابع زمنية (نفس التقرير يعطي نفس الملف بيتاً-بيتاً).
- **DOCX:** حزمة OOXML عبر `docx` (مفتوح المصدر، محلي) — عربي RTL، إحالات [n]، ملحق أدلة. **عيب حقيقي مكتشف وموثق:** الحزمة تغرس `new Date()` في خصائص النواة وأرشيف ZIP (غير قابل للتهيئة من واجهتها) — أُضيفت ما بعد معالجة (jszip) تثبّت الطوابع إلى قيمة ثابتة، فيصبح الملف حتمياً بيتاً-بيتاً (مُثبت في T-REP-008).
- **PDF:** يُرفض صريحاً (فشل-مغلق) — P5-027 هو قرار مقارنة المحركات (Typst/Playwright/React-PDF) للعربية RTL والخطوط وروابط الإحالات؛ لا توليد PDF قبل القرار ولا صمت.

## القياس

- T-REP-001..009 (9 اختبارات): كلها خضراء — رفض بلا إحالة، رفض إحالة معلقة، RTL وإحالات HTML قابلة للنقر، ملحق بالبصمات، حتمية HTML وDOCX، رفض PDF الصريح.
- الحزمة الكاملة **2889/0/6 (+9)**؛ lint/typecheck/build/governance exit 0.

## حدود معلنة

- DOCX: حتمية الملف تعتمد على تثبيت الطوابع في ما بعد المعالجة — أداة توليد PDF نفسها مؤجلة لقرار P5-027.
- القوالب مستقلة عن نموذج القضية الكامل (تستقبل نموذج التقرير مباشرة) — الربط بالإسقاطات والواجهة مهام لاحقة في الخارطة.
