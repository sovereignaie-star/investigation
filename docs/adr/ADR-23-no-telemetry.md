# ADR-23: لا قياس عن بعد ولا خدمات تحليلات خارجية افتراضياً

| البند | القيمة |
|---|---|
| الحالة | مُقرّر بتفويض |
| التاريخ | 2026-10-10 |
| المرجع | `docs/ROADMAP.md` 5.20 |

## السياق

الخطة الشاملة اقترحت Sentry وPostHog وRUM وBetter Uptime (C-23)، بينما المنتج محلي أولاً ويتعامل مع تحقيقات حساسة (E-06، NFR-10، NFR-11).

## القرار

لا يخرج من التثبيت أي قياس افتراضياً. أي أداة مراقبة اختيارية وذاتية الاستضافة، ويمكن للمستخدم فحص كل ما يُرسل (P8-018).

## البدائل

تحليلات سحابية افتراضية (تسرّب سياق تحقيقات).

## العواقب

رؤية أقل لاستخدام المنتج؛ تُعوَّض بمقابلات المستخدمين وBeta (R-15) وبقياس اختياري بعد GA.
