# ADR-01: البقاء على Vite + React 19 بدل Next.js

| البند | القيمة |
|---|---|
| الحالة | مُقرّر بتفويض |
| التاريخ | 2026-10-10 |
| المرجع | `docs/ROADMAP.md` 5.20 |

## السياق

المسودة الأولى للخارطة افترضت Next.js 14 وTailwind 3، بينما المستودع مبني فعلاً على Vite 7 وReact 19 وTailwind 4 (العيب D-045). المنتج تطبيق محطة عمل محلي أولاً بلا حاجة إلى عرض من جهة الخادم أو تحسين لمحركات البحث.

## القرار

نبقى على Vite 7 + React 19 + Tailwind 4، والتوجيه داخل العميل. الخادم المحلي (`apps/server`) منفصل ويقدّم الواجهة البرمجية فقط.

## البدائل

Next.js 14/15 (يضيف عرضاً من الخادم لا نحتاجه ويقيّد النشر المحلي وسطح المكتب)؛ Remix (نفس الاعتراض).

## العواقب

بناء أسرع وتجميع ثابت يصلح لـ Tauri (ADR-15) ولـ Docker؛ لا SSR ولا SEO، وهو مقبول لأن الصفحة `noindex` ولأن المنتج محلي. يُغلق D-045.
