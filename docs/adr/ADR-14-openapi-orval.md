# ADR-14: OpenAPI أولاً + Orval

| البند | القيمة |
|---|---|
| الحالة | مُقرّر بتفويض (قائم) |
| التاريخ | 2026-10-10 |
| المرجع | `docs/ROADMAP.md` 5.20 |

## السياق

المستودع يحوي `lib/api-spec` مع Orval يولّد `api-client-react` و`api-zod`.

## القرار

المواصفة OpenAPI هي مصدر الحقيقة للواجهة البرمجية، والعميل والمخططات تُولَّد منها.

## البدائل

tRPC (يربط العميل بالخادم بـ TypeScript ويُصعّب العملاء الخارجيين وSDK العامة P8-015)؛ GraphQL (عبء إضافي بلا حاجة في GA).

## العواقب

كل مسار جديد يبدأ بتعديل المواصفة (P2-019)، وNFR-17 يشترط توثيق كل المسارات بأمثلة.
