# ADR-10: الترخيص: AGPL-3.0-or-later

| البند | القيمة |
|---|---|
| الحالة | مُقرّر بتفويض |
| التاريخ | 2026-10-10 |
| المرجع | `docs/ROADMAP.md` 5.20 |

## السياق

كان `package.json` يعلن MIT بلا ملف ترخيص، والخطة الشاملة تركت الخيار مفتوحاً بين MIT وAGPL (C-14). المنتج قد يُشغَّل خدمةً عبر الشبكة.

## القرار

AGPL-3.0-or-later لكل كود المستودع، بنص الترخيص الرسمي في `LICENSE`.

## البدائل

MIT (يسمح بإغلاق نسخ مشتقة تُقدَّم خدمةً)؛ GPL-3.0 (لا يغطي الاستعمال عبر الشبكة)؛ ترخيص مزدوج (يتطلب اتفاقية مساهمين، يُعاد النظر فيه مع ADR-24).

## العواقب

كل من يقدّم نسخة معدلة عبر الشبكة يلزمه نشر مصدرها؛ مراجعة توافق تراخيص الاعتماديات إلزامية (P6-014، R-16). نُفّذ في P0-008.
