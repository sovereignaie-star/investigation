# ADR-13: Vitest للوحدة، Playwright للـ E2E، fast-check للخصائص، Stryker للطفرات

| البند | القيمة |
|---|---|
| الحالة | مُقرّر بتفويض |
| التاريخ | 2026-10-10 |
| المرجع | `docs/ROADMAP.md` 5.20 |

## السياق

لم تكن في المستودع اختبارات (D-040)، والمشروع على Vite.

## القرار

Vitest 3 للوحدة والتكامل (يشارك إعداد Vite)، Playwright للـ E2E والانحدار البصري، fast-check لاختبارات الخصائص في النواة والسجل، Stryker لاختبار الطفرات في الحزم الحرجة.

## البدائل

Jest (إعداد ESM/TS أثقل مع Vite)؛ Cypress (أبطأ ولا يدعم عدة متصفحات بالمستوى نفسه).

## العواقب

أهداف التغطية في الخارطة 8.5. نُفّذ أساس Vitest في P0-010.
