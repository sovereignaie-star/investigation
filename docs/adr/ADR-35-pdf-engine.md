# ADR-35: محرك PDF للتقارير العربية — Chromium (Playwright) على قالب HTML

- **الحالة:** مقبول (2026-10-24)
- **السياق:** مهمة الخارطة P5-027 «محرك PDF للتقارير العربية: مقارنة Typst وPlaywright وReact-PDF في RTL والخطوط وروابط الإحالات، وسجل قرار».
- **العلاقة:** يقرأ مع P5-010 (`@ir/reports` — قوالب HTML/DOCX)، وG-11 (سابقة إيجاد Chrome النظامي)، وADR-26a/b (حتمية المخازن)، والدليل `docs/evidence/2026-10-24-P5-027-pdf-comparison.md` وحصن المقارنة `tools/pdf-comparison/`.

## القرار

1. **المحرك المختار: Chromium عبر Playwright يطبع قالب HTML نفسه** (`renderReportHtml` ← `page.pdf`). مصدر حقيقة واحد للتقرير (HTML وPDF من نفس القالب)، والإحالات `<a href="#EV-n">` تبقى توضيحات روابط داخلية قابلة للنقر في PDF (مقيس — T-REP-010).
2. **الحتمية بتثبيت متساوي الطول لطوابع التاريخ** (`normalizePdfDates` — مرآة `pinDocxTimestamps`): Chromium يكتب «الآن» في `/CreationDate` و`/ModDate` (قيس 2026-10-24)؛ الاستبدال المتساوي الطول حرفاً-بحرف يبقي إزاحات xref سليمة؛ يثبته T-REP-011 (بايت-ل-بايت).
3. **فشل-مغلق عند غياب Chromium**: متصفح Playwright المضمّن أولاً ثم Chrome النظامي (`CHROME_PATH` أو PATH — سابقة G-11)؛ لا أحدهما = خطأ صريح، لا PDF صامت ولا تخطٍّ صامت.
4. **React-PDF مرفوض** — التشكيل العربي نفسه مكسور (قياس مرئي + طبقة ToUnicode تالفة بمحارف تحكم) — عيب قاتل لا يعالَج بتجميل.
5. **Typst وثائق بديل معلن لا القرار** — صحيح عربياً لكنه يتطلب قالباً ثانياً (ازدواج منطق العرض وخطر التباعد)، حزمته الرسمية مثبتة على 0.10، وتنزيله ثنائياً وقت التثبيت؛ إن احتيج مستقبلاً (مثل تنضيد طباعي متقدم) يُفتح بقرار جديد.

## العواقب

- `playwright` يصبح اعتماد تشغيل لـ`@ir/reports` (كان موجوداً في جذر المستودع لمسارات e2e).
- **النشر يحتاج Chromium في بيئة التشغيل** — حاوية الخادم الحالية لا تشمله؛ PDF في الحاوية يفشل صراحاً (حد معلن L-P5-027) حتى تُضاف (قرار نشر مستقل — P7-004).
- قبول P5-027: التقرير المرجعي طُبع صحيحاً بالمحركات الثلاثة (القياس أعلاه)، والمختار يحفظ الإحالات قابلة للنقر (T-REP-010) — نص القبول مستوفى.
