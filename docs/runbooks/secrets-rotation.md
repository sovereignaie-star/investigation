# كتيب: تدوير المفاتيح والأسرار (P7-006)

> النظام محلي أولاً: أصل الأسرار على جهاز المستخدم (مفتاح تثبيت، عبارات مرور). لا مخازن أسرار مركزية في هذا المستودع.

## متى يُستخدم

- شبهة/تأكيد تسريب مفتاح التثبيت أو عبارة مرور النسخ الاحتياطي.
- دورة مجدولة، أو فقدان الجهاز، أو مشاركة الجهاز.

## الخطوات

1. ولّد مفتاح تثبيت جديداً لنطاق المهمة (لا تعيد استخدام المفتاح القديم).
2. أعد النسخ الاحتياطي بالمفتاح الجديد قبل أي شيء آخر (backup-restore.md) — القضايا القديمة تبقى قابلة للفتح بالمفتاح القديم: أرشفه مشفراً ثم أعد النسخ والتحقق.
3. دوّر عبارات مرور النسخ الاحتياطي: أنشئ حزم نسخ جديدة بالعبارة الجديدة وتحقق منها قبل حذف القديمة.
4. أي سر مؤسسي في CI (رموز GitHub) يُدار من إعدادات المستودع — لا يوضع سر في الكود أبداً (gitleaks يحرس).
5. لا يوجد سر في المستودع نفسه يحتاج تدويراً — إن وُجد فذلك حادثة (incident-response.md).

## التحقق

- فتح قضية قديمة بالمفتاح الجديد ينجح، وفحص سلسلة السجل الموقعة يمر.
- `gh api repos/<owner>/<repo>/secret-scanning/alerts` لا تنبيهات مفتوحة.

## التصعيد

- فقدان المفتاح مع فقدان النسخ => فقدان بيانات لا رجعة فيه (تصميم مقصود) — وثّق في DECLARED_LIMITS إن اتسع النطاق.
- تسريب مؤكد في سياق إفصاح عام => P7-007.
