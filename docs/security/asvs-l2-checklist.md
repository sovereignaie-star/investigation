# قائمة تحقق OWASP ASVS 4.0.3 — المستوى 2 (P6-001)

**المصدر الرسمي:** OWASP Application Security Verification Standard 4.0.3 (ترخيص CC BY-SA 4.0) — فصول `4.0/en` من مستودع OWASP/ASVS عند الإيداع `4963e2bc55e8f9607c05d88dafb0c52c10ba4a4c`. البنود الرسمية الـ 253 بمستوى L2 مستخرجة في `docs/security/asvs/asvs-4.0.3-l2.csv` (الأداة: `tools/asvs/extract-l2.mjs`).

**الحارس:** `scripts/governance/asvs.test.mjs` (T-ASVS-001..005) يرفض أي بند غير مغطى أو مكرر أو «منجز» بلا دليل قابل للتحقق أو «مبرر» فارغاً — يعمل في CI مع فحوص الحوكمة.

**الملخص:** 147 بنداً منجزاً بدليل قابل للتحقق، و106 بنداً مبرراً (لا ينطبق على نموذج التطبيق المحلي أو مؤجل لمهمة خارطة موثقة — كل مبرر صريح أعلاه في صفه).

## التوقيع

قائمة تحقق موقعة — قائد الهندسة التنفيذية بتكليف المالك (الجلسة الحالية، 2026-10-24) — المهمة P6-001. الحدود والفجوات المعلنة في `docs/DECLARED_LIMITS.md` (L-P6-001). لا ادعاء إكمال لأي بند مؤجل: كل «مبرر» أعلاه يحدد سببه ومصدره.
