# نموذج التهديدات STRIDE (P6-002)

**التاريخ:** 2026-10-24 — **المهمة:** P6-002 — **التوقيع:** قائد الهندسة التنفيذية بتكليف المالك (الجلسة الحالية). بناء على نمذجة P2-003 (سجل القبول `docs/security/P2-003-ACCEPTANCE.md` وADR-08) وتوسيعها منهجياً بفئات STRIDE الست على كل حدود الثقة.

**الحارس:** `scripts/governance/threat-model.test.mjs` (T-TM-001..005) في CI و`governance:test` — يرفض أي تهديد بلا تخفيف موثق أو خطر متبقٍ صريح، وأي حد ثقة غير مغطى.

**شرط القبول «مراجعة ثانية»:** مراجعة D-8 ملغاة نهائياً بأمر المالك التأسيسي — الحارس الآلي هنا هو المراجعة الثانية (كل ادعاء تخفيف بمصدر قابل لإعادة التشغيل)، والاعتماد الخارجي هو P6-003.

## الأصول داخل نطاق النموذج

بيانات القضية المشفرة (مغلفات AES-256-GCM)، أسرار الخزنة (مفاتيح المزودين)، مفتاح الجلسة، سلسلة التدقيق الموقعة، أدلة القضية (blobs بعنونة المحتوى)، التقارير المولدة، إخراج المحولات المعزولة.

## حدود الثقة (ADR-08 / P2-003)

1. المتصفح ↔ الخادم (127.0.0.1، جلسة كوكي + CSRF)
2. الخادم ↔ بوابة الخروج (@ir/egress، مسار الشبكة الوحيد)
3. البوابة ↔ المزودون الخارجيون (HTTPS فاشل-مغلق، قائمة مضيفين)
4. الخادم ↔ العزل sandbox (bwrap، IPC، بلا شبكة افتراضياً)
5. الخادم ↔ المخزن المشفر (case.sqlite المغلق بمفاتيح Argon2id)
6. المشغّل ↔ CLI (أوامر صريحة، تفعيل شبكي بقرار)
